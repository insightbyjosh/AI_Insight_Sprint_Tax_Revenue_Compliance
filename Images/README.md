# Images

This folder contains selected visual outputs from AI Insight Sprint™ Case Study #2.

The visuals support the analytical findings presented in the case study, including:

- Executive revenue performance
- Revenue and payment intelligence
- Tax compliance and payment behaviour
- Taxpayer and geographic intelligence
- Executive decision intelligence

Visual outputs were developed using Power BI and form part of the supporting evidence for the case study.

> **Data Note:** All visuals are based on a simulated tax administration dataset created for analytical demonstration and portfolio purposes.
