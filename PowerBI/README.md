# Power BI Dashboard

This folder contains the Power BI dashboard developed for AI Insight Sprint™ Case Study #2.

## Dashboard Pages

- Executive Overview
- Revenue Intelligence
- Tax Compliance Intelligence
- Taxpayer & Geographic Intelligence
- Executive Decision Intelligence

## Tools

- Power BI
- DAX
- Power Query
- Python

The dashboard translates validated analytical findings into interactive revenue, compliance, taxpayer and geographic intelligence.

> **Data Note:** This case study uses a simulated tax administration dataset created for analytical demonstration and portfolio purposes. It does not represent official Nigerian government revenue records.
